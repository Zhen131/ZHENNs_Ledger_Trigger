# Test matrix

This file lists, for each of the 26 test scenarios in [contract-spec.md](contract-spec.md) (part 6), the tests that cover it, and then other important tests besides those.

How to read it:

- Every test whose own title starts with a scenario number, S01 to S26, is listed in the row of that number. Titles are written exactly as in the source. A `${...}` in a title means the test runs once for each case in a list just above it in the source, for example once for each kind of caller that must be refused.
- File names are relative to the root of the repository.
- The expected results are written in four forms: a status change (`Open -> Filled`), "transaction must revert", "second call must revert", and "explicit error".

`npm run check` checks this file in its `scenarios` step (`scripts/scenarios.ts`): every scenario has exactly one row; every title named here, in either table, is a test in the file named next to it; and every test whose title starts with a scenario number is listed in the row of that number. To see the scenario tests as the check finds them in the source, run `node scripts/scenarios.ts --list`.
